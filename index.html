Présentation de ce site

Bonjour et bienvenue sur khuzd, le site d'un moussaillon naviguant sur le web. Tout d'abord avant de me présenter personnelelment, je vais faire une présentation de ce site et du pourquoi et comment.
La création de ce site à plusieurs but : Tout d'abord Pratiquer le developemet web en étant pro-actif, j'ai comme beaucoup de personne regardé des tutos sur youtube, lu des articles, apris avec le site du zéro (l'ancien nom de Oen Class Roomm) mais je n'ai jamais réussi à trouver la motivation de finir ces cours car meme si certains vous oblige à "coder" (comme freecodecamp), il m'arrive d'avoir l'imprression d'essayer d'aprendre le dictionnaire ! Jusqu'au jour ou j'ai trouvé une idée de projet intéréssant qui me permette d eme motiver à mettre les mains le cambouis ! Cette idée est de pouvoir accéder rapidement à mes favoris internet dans un premier temps (ressources vidéos plus tard) sur l'ensemble de mes appareils sans passer par un services. Ce sont les "awesome-list" sur github qui m'ont donner cette idée.
Comme vous l'aurez devinez je suis auto-didacte et j'ai l'unique ambition de coder du html pour l'instant, pour pratiquer rapidement mes connaissances.
De plus si vous utiliser des services comme WayBack Machine vous vous rendrez compte qu'il y a eu et aura plusieurs versions de ce site et c'est normales car il faut forger pour devenir forgerons ! Petit disclaimer en ce qui concerne de l'utilisation de l'IA, je l'utilise pour corriger mes faute d'orthographes pricipalement et dans le cadre de Visual Studio Code,d'ailleurs je ne sais plus si j'utilise des "emmet" ou de l'IA. Je suis hébergé chez Github via Github Page et j'utilise comme editeur Visual Studio Code que je trouve maintenant avec Copilot trop "complet".
J'utilise Git comme outil de version. Maintenant que la présentation générale du site est fait, je vais vous laisser découvrir le site, vous trouverer les ressources web que j'ai pu trouvé sur la page "Ressources web", les différents projets en cours ou terminés sur la page "Projets", une page "Mes outils faits-maison" ou vous trouverez les outils que je me suis crées avec l'aide de l'IA,princiapalmeent des scripts Python d'automatisation de tâche; un espace blog ou je publie les modifications du site principalements.
